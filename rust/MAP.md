This table tracks the Rust implementation separately from compatibility code
that must remain available to existing Kotlin Multiplatform consumers.

| Category and favorites filtering | `CatalogViewModel.kt` retains a Kotlin fallback | `sfstudio-core::Catalog::search_filtered` via C ABI | `VERIFIED`; exact Kotlin/Rust parity and cross-OS JNA tests pass for category, favorites, blank, typo, and Unicode queries in run #17 |
| Cross-language core entry point | Rust core had no stable foreign-language ABI | `sfstudio-ffi` C ABI + `include/sfstudio.h` | `IN_PROGRESS`; search, filtering, filter-selection transitions, codegen, favorites, metadata, complete glyph/layer JSON, glyph geometry and point interpolation, Apple animation frames, layer appearance, draw-field levels, and MCP config generation are exposed; Android JNI rendering adapters pass source compilation and four-ABI packaging in run #44849774443, with device runtime parity pending; iOS point parity passed in run #44854205293, animation/appearance parity in run #44857761656, and draw-field C-interop checks in run #44859231638; JS Node parity passes and Kotlin/Wasm compiles, with browser runtime validation pending |

The Rust MCP binary is bundled into standalone MCP assemblies and desktop
installers. Packaged `--mcp` invocations delegate to it; classpath-based Gradle
launches keep the Kotlin implementation as a development fallback.
